# Contributing

Thanks for taking an interest in this portfolio repository.

This repository primarily contains profile documentation, project indexes, visual assets, and lightweight automation.

## Ways to contribute

- Report broken links or rendering problems.
- Suggest corrections to project descriptions.
- Point out outdated technology or documentation references.
- Suggest improvements to accessibility and readability.

## Before opening an issue or pull request

1. Search existing issues to avoid duplicates.
2. Describe the affected file or section.
3. Explain the problem and the expected result.
4. Include screenshots for visual rendering issues when possible.
5. Keep project claims factual and traceable to source repositories.

## Content and evidence standards

- Do not add fabricated application screenshots, benchmark results, or project metrics.
- Clearly label concept illustrations and diagrams.
- Do not publish credentials, API keys, personal data, or private project information.
- Keep descriptions concise, accurate, and respectful.

## Pull requests

- Make focused changes.
- Preserve existing Markdown and SVG conventions.
- Check links and image paths before submitting.
- Explain what changed and how it was verified.

By contributing, you agree that your contributions may be reviewed and incorporated into this public portfolio repository.
