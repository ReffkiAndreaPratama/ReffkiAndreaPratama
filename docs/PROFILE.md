# Reffki Andrea Pratama

> Informatics student · Software developer · Technology explorer

## Professional summary

I am an Informatics student at Universitas Bengkulu, Faculty of Engineering. My project interests include web application development, backend systems, computer vision, machine learning, geospatial applications, and Linux infrastructure.

I approach learning through practical implementation: understand a problem, define scope, design the system, build incrementally, validate the result, and document what was learned.

## Focus areas

- **Software engineering:** web applications, backend workflows, database design, and maintainable code.
- **Computer vision and machine learning:** image preprocessing, feature engineering, model comparison, and evaluation.
- **Geospatial technology:** interactive maps, spatial data processing, and GIS workflows.
- **Systems and infrastructure:** Linux services, self-hosting, deployment, and troubleshooting.
- **Software analysis:** API behaviour and reverse-engineering fundamentals in controlled learning environments.
