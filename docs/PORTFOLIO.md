# Reffki Andrea Pratama — Project Portfolio

> Informatics student · Software development · Computer vision · Geospatial technology

This document is a concise index of selected work. Project status and technical claims should be read from the linked repositories; this portfolio does not imply that every experiment is production-ready.

## Featured projects

### 1. Coastal Tourism WebGIS
**Purpose:** Present tourism destinations around Bengkulu through searchable information and an interactive map.

- **Core work:** destination catalogue, destination details, map markers, visitor reviews, and administration.
- **Technology:** Laravel, PHP, Blade, Tailwind CSS, Alpine.js, Leaflet, MySQL/SQLite.
- **Evidence:** [Source repository](https://github.com/ReffkiAndreaPratama/Websiste-Peta-Interaktif-Pariwisata-Bengkulu)

### 2. SimAset — Office Asset Management
**Purpose:** Support office asset recording and operational tracking for the RBTV Bengkulu practical-work project.

- **Core work:** asset and room records, QR identification, maintenance records, audit trail, and reporting.
- **Technology:** Laravel, PHP, MySQL, Blade, Bootstrap, JavaScript.
- **Evidence:** [Source repository](https://github.com/ReffkiAndreaPratama/Project-kp-simaset)

### 3. RiceVision AI
**Purpose:** Explore rice-image classification using handcrafted visual features and classical machine learning.

- **Core work:** preprocessing, color/texture/shape features, GLCM, SVM and Random Forest comparison, prediction interface.
- **Technology:** Python, OpenCV, scikit-image, scikit-learn, Streamlit.
- **Evidence:** [Source repository](https://github.com/ReffkiAndreaPratama/Sesi-4---RICE-CLASSIFICATION-AI)

### 4. CodeVault
**Purpose:** Organize reusable code snippets in a searchable personal library.

- **Core work:** snippet editor, tags, collections, search, version history, diff, import/export.
- **Technology:** Laravel, PHP, Alpine.js, Tailwind CSS, CodeMirror.
- **Evidence:** [Source repository](https://github.com/ReffkiAndreaPratama/codevault)

### 5. Speech-to-Text Bahasa Bengkulu
**Purpose:** Investigate speech recognition for a regional language where transcribed audio data is a key constraint.

- **Core work:** dataset preparation, audio preprocessing, CNN–BiLSTM–CTC pipeline, WER/CER evaluation.
- **Technology:** Python, audio processing, deep learning.
- **Status:** Research pipeline in development; no accuracy claim is made before suitable data collection, training, and evaluation.
- **Evidence:** [Source repository](https://github.com/ReffkiAndreaPratama/speachtotext)

## Engineering approach

1. Define the problem, intended users, and project boundaries.
2. Define data structures and feature requirements before implementation.
3. Build in small, testable increments.
4. Validate behaviour, edge cases, and model metrics where relevant.
5. Document setup, design decisions, and known limitations.
