# Project Catalogue

A concise catalogue of selected academic, practical-work, and personal projects. Descriptions summarize project scope; consult each repository for current implementation details.

## Featured projects

### Coastal Tourism WebGIS
Interactive tourism information for destinations around Bengkulu, combining destination content, map visualization, and administration.

- Focus: web application development, geospatial data, interactive mapping.
- Stack: Laravel, PHP, Blade, Leaflet, Tailwind CSS, MySQL/SQLite.
- Repository: [WebGIS Pariwisata Bengkulu](https://github.com/ReffkiAndreaPratama/Websiste-Peta-Interaktif-Pariwisata-Bengkulu)

### SimAset — Office Asset Management
A web-based office asset management project developed for RBTV Bengkulu during practical work.

- Focus: asset records, QR identification, maintenance tracking, audit trail, and reporting.
- Stack: Laravel, PHP, MySQL, Blade, Bootstrap, JavaScript.
- Repository: [Project KP SimAset](https://github.com/ReffkiAndreaPratama/Project-kp-simaset)

### RiceVision AI
A rice image classification coursework project using handcrafted image features and classical machine-learning models.

- Focus: preprocessing, color/texture/shape features, GLCM, SVM, Random Forest.
- Stack: Python, OpenCV, scikit-image, scikit-learn, Streamlit.
- Repository: [Rice Classification AI](https://github.com/ReffkiAndreaPratama/Sesi-4---RICE-CLASSIFICATION-AI)

### CodeVault
A code-snippet manager intended to organize, search, version, and reuse source-code fragments.

- Focus: editor, tags, collections, search, version history, import/export.
- Stack: Laravel, PHP, Alpine.js, Tailwind CSS, CodeMirror.
- Repository: [CodeVault](https://github.com/ReffkiAndreaPratama/codevault)

### Speech-to-Text Bahasa Bengkulu
A research-oriented pipeline exploring speech recognition for a regional language.

- Focus: audio preparation, CNN–BiLSTM–CTC experimentation, WER/CER evaluation.
- Status: research pipeline in development; no recognition accuracy is claimed before suitable dataset collection, training, and evaluation.
- Repository: [Speech-to-Text](https://github.com/ReffkiAndreaPratama/speachtotext)
