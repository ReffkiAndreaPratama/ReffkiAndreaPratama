# Security Policy

## Scope

This policy applies to this public profile repository and its documentation, static assets, and GitHub Actions workflows.

For security issues in a linked project, please report the issue in that project's own repository and follow its security policy.

## Reporting a vulnerability

Please do not publish credentials, tokens, private data, or an exploitable vulnerability in a public issue.

Use GitHub's **Report a vulnerability** feature for this repository if private vulnerability reporting is enabled. If it is unavailable, contact me through my [GitHub profile](https://github.com/ReffkiAndreaPratama) and provide a concise description and reproduction details.

## Response

I will review reports as time and project scope allow. This is a personal portfolio repository and does not provide a guaranteed response-time or service-level agreement.

## Safe disclosure

Please give me a reasonable opportunity to investigate and address a valid report before publicly disclosing technical details.
